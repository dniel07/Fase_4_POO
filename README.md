# Sistema Integral de Gestión de Clientes, Servicios y Reservas

## Proyecto: Software FJ

### Descripción
Software FJ es un sistema desarrollado en Python con programación orientada a objetos para gestionar clientes, servicios y reservas. El proyecto utiliza clases, encapsulamiento, herencia, abstracción, polimorfismo y manejo de excepciones.

### Objetivo
Implementar una solución modular que permita registrar clientes, administrar servicios, gestionar reservas y calcular costos, validando los datos y registrando los eventos relevantes del sistema.

### Alcance
- Gestión y validación de clientes.
- Definición de servicios especializados.
- Administración del ciclo de vida de las reservas.
- Cálculo de costos con impuestos y descuentos.
- Manejo de excepciones estándar y personalizadas.
- Registro de eventos y errores en archivos de log.
- Pruebas de operaciones válidas e inválidas sin utilizar bases de datos.

### Tecnologías
- Python 3.
- Jupyter Notebook.
- Git y GitHub.

### Estructura del proyecto
El código fuente se organiza en módulos independientes para facilitar el desarrollo colaborativo, las pruebas y el mantenimiento.

### Equipo de trabajo
Proyecto académico desarrollado colaborativamente por cuatro estudiantes.

### Ejecución
Las instrucciones definitivas de instalación y ejecución se incorporarán cuando se integre y pruebe la versión final del sistema.
