# Software FJ — Gestión de Clientes, Servicios y Reservas

## Descripción
Proyecto académico en Python que aplica programación orientada a objetos. Gestiona clientes, servicios especializados y reservas. Los datos se almacenan en objetos y listas en memoria; no se utiliza base de datos. Los eventos se guardan en un archivo de log.

## Requisitos
Python 3.10 o superior. No requiere paquetes externos.

## Ejecución
Desde la carpeta raíz:
```bash
python -m src.main
```

## Archivos
- `src/excepciones.py`: errores personalizados.
- `src/entidades.py`: clase abstracta Entidad.
- `src/clientes.py`: clase Cliente y validaciones.
- `src/servicios.py`: Servicio y tres servicios derivados.
- `src/reservas.py`: gestión de reservas.
- `src/logs.py`: registro de eventos.
- `src/main.py`: demostración y pruebas.
- `notebooks/SoftwareFJ_Fase4.ipynb`: componente práctico.
- `evidencias/`: capturas reales del grupo.

## Colaboración
Cada integrante debe trabajar en su rama, realizar commits descriptivos y participar en la revisión e integración. No incluir datos personales reales.
